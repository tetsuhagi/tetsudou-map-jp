らくラクびわこ完全ガイド｜大阪〜米原・草津の停車駅・681系／683系とキハ189系・旧びわこエクスプレスの通勤特急の乗り方

最終更新: 2026年9月 / カテゴリ: 路線詳細 / 特急

💡 まずはここだけ！3つの要点

  • らくラクびわこは、大阪と米原・草津を琵琶湖線・JR京都線経由で結ぶJR西日本の通勤特急。平日のみ、朝に上り1本・夕方以降に下り2本という少数精鋭の運行です
  • 停車駅は高槻と能登川を除く新快速の停車駅とほぼ同じ。「速く着くための特急」ではなく「確実に座るための特急」という性格がはっきりしています
  • 全車指定席。列車によって車両が変わり、681系・683系の電車が入る列車にはグリーン車があり、キハ189系というディーゼルカーが入る列車は普通車のみです
🙋‍♂️
通勤電車の線路に特急が混ざってるの、旅行者からするとちょっと不思議な光景やな〜

らくラクびわこは、大阪駅と米原駅・草津駅を琵琶湖線・JR京都線（東海道本線）経由で結ぶJR西日本の特急列車です。観光地へ向かう列車ではなく、滋賀から大阪へ通う人を座って運ぶための通勤特急。2024年春までは「びわこエクスプレス」という名前で走っていた列車で、その前身までさかのぼると1980年代のホームライナーに行き着きます。この記事では、名前が三度変わったこの列車の歩み、平日だけの運行イメージ、新快速とほぼ同じ停車駅、列車ごとに変わる車両と座席、きっぷの買い方、そして「らくラク」を名乗る兄弟列車との関係までを解説します。

ご注意: 本記事の情報は2026年9月時点のおおよその目安です。 らくラクびわこは本数・運転日・停車駅・使用車両・座席の扱いがダイヤ改正等で変わることがあります。 実際の時刻・料金・設備・きっぷの発売条件などは JR西日本「JRおでかけネット」のらくラクびわこ案内ページ 等の公式情報で必ず最新の内容をご確認ください。

らくラクびわことは — 速さではなく、席を買う特急

平日の夕方、大阪駅の在来線ホームに「特急 米原」という行き先が表示されます。特急と聞けば、ふつうは温泉や海や城が待っている方向を思い浮かべるところですが、この列車に乗り込むのはスーツ姿や仕事帰りの人がほとんど。手荷物も、スーツケースではなく鞄です。

それもそのはずで、らくラクびわこは滋賀と大阪のあいだを通う人のための特急です。大阪から米原までの区間には、JR西日本が誇る新快速という強力な列車が日中でもひっきりなしに走っていて、速さという点ではすでに十分に満たされています。そこへあえて特急を走らせる理由は、速さではありません。

売っているのは、座席そのものです。朝の上り、夕方以降の下りという、いちばん混み合う時間帯に、追加料金を払えば必ず座って移動できる。滋賀県から大阪まではおおむね1時間前後かかるので、その時間を立って過ごすか、リクライニングシートで過ごすかの差はかなり大きいわけです。特急らしい派手さはありませんが、使う人にとっては実利がはっきりしている列車です。

「びわこライナー」から「らくラク」へ — 名前が三度変わった列車

この列車がおもしろいのは、同じ役割を四十年近く続けながら、肩書きだけが少しずつ変わってきたところです。

出発点は1987年、国鉄が分割民営化されてまもない時期に走り始めた「びわこライナー」でした。当時は特急ではなく、座席定員制のホームライナー。北陸方面へ向かう特急の車両が、営業運転に出る前や戻ってきたあとの時間を使って通勤客を運ぶという、車両のすきま時間を活用した列車です。乗車券に安価なライナー券を足せば座れるという仕組みで、当時は特急形の車両に安く乗れる「知る人ぞ知る」存在でもありました。

転機は2003年。北陸方面に新型車両が入ったことで使う車両が入れ替わり、それに合わせて列車そのものが特急「びわこエクスプレス」に格上げされます。ライナー券ではなく特急券が必要になった代わりに、特急としての案内や設備が整いました。その後、2019年からは案内上「通勤特急」という呼び方が使われるようになり、2021年春には南草津が停車駅に加わるとともに全車指定席へ。自由席をめぐる席取り競争がなくなり、「買った時点で座れる」列車に変わりました。

2024年春、名前が「らくラクびわこ」になった

そして2024年3月16日のダイヤ改正で、列車名が「らくラクびわこ」に改められました。名前が変わった理由は、この列車の都合というよりブランドの統一です。JR西日本の大阪都市圏（アーバンネットワーク）には、同じように通勤時間帯の着席需要に応える特急が他にもあり、それらを「らくラク○○」という名前でそろえることになりました。

そのため、長く親しまれた「びわこエクスプレス」という名前はこのとき役目を終えています。時刻表や駅の案内はすでに新しい名前に置き換わっていますから、検索するときは「らくラクびわこ」で探すほうが早く目的の情報にたどり着けます。

運行会社と運行区間

  • 運行会社: JR西日本
  • 運行区間: 大阪 〜 米原／大阪 〜 草津（東海道本線〈JR京都線・琵琶湖線〉経由）
  • 種別: 特急（通勤特急）／2021年3月から全車指定席
  • 使用車両: 681系・683系（電車）／キハ189系（ディーゼルカー）※列車により異なる
  • 運行日: 平日のみ（土曜・休日は運転なし）
  • 運行本数: 1日3本。朝に米原発大阪行きが1本、夕方以降に大阪発米原行きと大阪発草津行きが1本ずつ（2026年9月時点の目安）
  • 所要時間: 大阪〜米原でおおよそ1時間半前後
  • 旧列車名: びわこエクスプレス（2003〜2024年）／びわこライナー（1987〜2003年）

本数の少なさは、この列車の性格をそのまま表しています。あくまで通勤・帰宅のピークに合わせた列車なので、日中や土日に乗ることはできません。旅行で琵琶湖方面へ向かう場合は、新快速が実質的な主役になります。運転日と本数はダイヤ改正で見直されることがあるため、乗る前に最新の時刻表でご確認ください。

停車駅 — 新快速から2駅だけ引いた形

特急と聞くと、主要駅だけにぽつぽつ停まる姿を想像しますが、らくラクびわこはそうではありません。停車駅はむしろ多く、高槻と能登川を除く新快速の停車駅に停まります。通勤客を拾うための列車なので、細かく停めたほうが都合がよいわけです。

主な停車駅

上り（米原 → 大阪／朝）: 米原 → 彦根 → 近江八幡 → 野洲 → 守山 → 草津 → 南草津 → 石山 → 大津 → 山科 → 京都 → 新大阪 → 大阪

下り（大阪 → 米原・草津／夕方以降）: 大阪 → 新大阪 → 京都 → 山科 → 大津 → 石山 → 南草津 → 草津 →（米原行きはさらに）守山 → 野洲 → 近江八幡 → 彦根 → 米原

草津行きの列車は草津が終点になるため、そこから先の守山・野洲・近江八幡・彦根・米原方面へは普通列車や新快速に乗り継ぐ形になります。停車駅は改正で変わることがあるので、最新の案内をご確認ください。

南草津が加わった意味

停車駅のなかで少し異色なのが南草津です。1994年に開業した比較的新しい駅ですが、大学や事業所の立地で利用者が伸び続け、いまでは滋賀県内でも有数の乗降客数を持つ駅に育ちました。2021年春にこの駅が停車駅へ加わったことは、らくラクびわこが「昔からの主要駅を結ぶ特急」ではなく、いま人が乗り降りしている場所に合わせて形を変える列車であることをよく示しています。

車両 — 電車の日と、ディーゼルカーの日がある

この列車のいちばんの意外性は、ここにあります。列車によって、来る車両がまったく違うのです。しかも片方は電車で、もう片方はディーゼルカーです。

朝の上り列車と、夕方以降の草津行きには、681系・683系が入ります。サンダーバードやしらさぎでおなじみの、北陸方面の特急で活躍してきた電車です。基本は6両で、日によっては9両になることもあります。これらの列車にはグリーン車も連結されています。

一方、夕方の米原行きに入るのがキハ189系というディーゼルカーです。本来ははまかぜとして、播但線や山陰本線の電化されていない区間を走るために用意された車両。そのはまかぜが大阪駅に到着したあと、車内点検と清掃を済ませて、今度はらくラクびわことして米原へ折り返していきます。編成は3両が基本で、日によって6両になることもあり、こちらにグリーン車はありません。

つまり、電化された東海道本線を、ディーゼルカーの特急が堂々と走るという状況が平日の夕方に毎日起きているわけです。新快速の走る線路にエンジン音の列車が混ざる光景は、関西のなかでもかなり珍しい部類に入ります。なお、はまかぜから続けて乗ることはできず、大阪でいったん降りる必要があります。

どの列車にどちらの車両が入るかは時期によって変わることがあるため、狙って乗りたい場合は公式の車両案内で編成を確認してから選ぶのが確実です。

座席ときっぷ — 全車指定席、グリーン車は列車による

らくラクびわこは2021年3月から全車指定席です。自由席はないため、乗るには必ず指定席をおさえる必要があります。裏を返せば、席を確保した時点で座れることが確定するので、ホームに早く並ぶ必要はありません。通勤列車としては、これがいちばん大きな価値でしょう。

グリーン車は列車によって連結されている場合とされていない場合があります。681系・683系が入る列車にはグリーン車がありますが、キハ189系の列車は普通車のみです。グリーン車を使いたい場合は、購入の時点で編成を確認しておくと間違いがありません。

料金の考え方

料金は「乗車券＋指定席特急券」の組み合わせが基本です。グリーン車を使う場合は、指定席特急券に代えてグリーン券が必要になります。JR西日本のネット予約サービス（e5489）には、きっぷを受け取らずに乗れるチケットレス特急券が設定されていて、通勤で日常的に使うならこちらのほうが手間も料金も抑えられる場合があります。金額や発売条件は改定されることがあるため、購入時に最新の内容をご確認ください。

車内の設備

パソコンを開きたい人が気にするのはコンセントですが、公式の車両案内によれば、グリーン車は全席に、普通車は各号車の最前部・最後部に設置されています。普通車の場合は席の位置によってコンセントが使えないことがあるので、作業しながら帰りたい日はモバイルバッテリーを持っておくと安心です。全車禁煙です。

「らくラク」3兄弟 — はりま・やまととの関係

2024年春の改名によって、らくラクびわこはひとりの列車ではなく、シリーズの一員になりました。大阪都市圏の三方向へ、それぞれ着席通勤のための特急が走っています。

列車名おもな区間性格
らくラクびわこ 大阪 〜 米原・草津 滋賀方面（琵琶湖線）の担当。旧びわこエクスプレス
らくラクはりま 京都・新大阪 〜 網干 播磨方面（JR神戸線・山陽本線）の担当。2019年デビューで、この「らくラク」の名づけ親にあたる
らくラクやまと 新大阪 〜 奈良 奈良方面（関西本線・大阪環状線経由）の担当。2024年春から平日に運転

先に走り始めたのは、2019年春デビューのらくラクはりまでした。この列車が「らくラク」という名前で着席通勤という商品を立ち上げ、2024年春にびわこエクスプレスが改名し、奈良方面のらくラクやまとが加わって三方向がそろった、という順番です。名前を見ただけで行き先と役割がわかるので、通勤客にとっては覚えやすい整理といえます。

沿線 — 通勤路線であり、城と湖の路線でもある

らくラクびわこが走る琵琶湖線は、平日の朝夕こそ通勤路線の顔をしていますが、停車駅の並びを見ると観光地がずらりと続いています。らくラクびわこ自体は平日の通勤時間帯しか走らないため観光向きではありませんが、同じ区間を新快速で旅するときの参考として挙げておきます（所要は2026年9月時点の目安です）。

  • 彦根（彦根駅から徒歩圏）: 天守が国宝に指定されている彦根城。城下町の夢京橋キャッスルロードもあわせて歩ける
  • 近江八幡（近江八幡駅からバス）: 八幡堀の水郷風景と、ヴォーリズが手がけた近代建築が残る街。近江牛も名物
  • 大津（大津駅・石山駅から）: 琵琶湖のほとりの県庁所在地。石山駅からは紫式部ゆかりの石山寺、京阪石山坂本線で坂本方面の日吉大社・延暦寺へも抜けられる
  • 草津（草津駅から）: 東海道と中山道が合流する宿場町で、草津宿本陣が残る。群馬の草津温泉とは別の場所なので、宿を探すときは要注意
  • 米原（米原駅）: 東海道新幹線と在来線が交わる乗り換えの要衝。北陸本線が分かれていく起点でもある

ちなみに終点の米原は、東海道新幹線が停まる駅のなかでもとりわけ乗り換えの性格が強い駅です。夕方の下り列車で米原まで乗り通すと、通勤特急の終着なのに新幹線ホームが頭上にあるという、少し不思議な到着になります。

予約・乗り方のコツ

通勤特急なので、観光特急とは気をつけるポイントがだいぶ違います。

  • 平日のみの運転。土曜・休日に乗ることはできないので、旅行の行程に組み込むなら曜日を先に確認する
  • 1日3本しかない。「次の特急を待つ」という選択肢が実質ないため、時刻は先に固めておく
  • 全車指定席。当日でも空席があれば乗れるが、通勤需要の列車なのでピーク日は早めにおさえるほうが安全
  • グリーン車に乗りたいなら、その列車に連結があるかを購入前に確認する（キハ189系の列車には連結なし）
  • ネット予約（e5489）のチケットレス特急券は、駅で受け取る手間が省ける。日常的に使うなら登録しておくと快適
  • 草津行きの列車は草津が終点。その先へ行く場合は乗り継ぎが必要になる
  • 観光で琵琶湖方面へ行くなら、素直に新快速のほうが本数も多く使いやすい

よくある質問

Q. びわこエクスプレスは廃止されたのですか？

列車そのものは走っています。2024年3月のダイヤ改正で列車名が「らくラクびわこ」に変更されたもので、区間や役割は引き継がれています。駅の案内や時刻表はすべて新しい名前になっているため、情報を探すときは「らくラクびわこ」で検索してください。

Q. 土日に乗ることはできますか？

できません。平日のみの運転です。同じ区間には新快速が土日も多数走っていますので、観光であればそちらが実質的な選択肢になります。

Q. 自由席はありますか？

ありません。2021年3月から全車指定席になっています。乗車券に加えて指定席特急券（グリーン車の場合はグリーン券）が必要です。

Q. 新快速と比べて、そんなに速いのですか？

停車駅がほぼ同じなので、劇的に速いわけではありません。この列車の価値は所要時間の短縮ではなく、追加料金を払って確実に座れることにあります。混雑する時間帯に1時間前後を座って過ごせる、という点で選ばれている列車です。

Q. どの列車にディーゼルカーが来るのですか？

夕方の米原行きの列車に、はまかぜで使われるキハ189系が入ります。朝の上り列車と草津行きには681系・683系の電車が入ります。ただし使用車両は変更されることがあるため、確実に乗りたい場合でも公式の編成案内で確認したうえで、当日変更の可能性も見ておくのが無難です。

Q. はまかぜから乗り継いで、そのまま乗っていられますか？

できません。大阪到着後に車内点検と清掃が入るため、ドアはいったん閉められます。続けて乗る場合も一度降りて、あらためてらくラクびわことして乗り直す形になります。
